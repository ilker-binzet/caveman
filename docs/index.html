    thumb_up
    Caveman wins
    
        
      
          
    • Long, chatty answers — explanations, reviews, debugging walk-throughs over ~1.5–2k output tokens.
      • 
          
    • Long sessions — per-reply savings add up, the rule cost stays flat.
      • 
          
    • Reading speed — shorter replies finish sooner and read faster. Often the real win.
      • 
        
    
      
    
      
    
        
    thumb_down
    Caveman loses
    
        
      
          
    • Already-short Q&A — saving 70–100 output tokens while adding ~1k input per turn is a net loss.
      • 
          
    • Pay-per-request agents — a shorter answer is still the same request.
      • 
          
    • Some tool-side counters — rule re-injection and retries can swamp the savings. Always A/B.

    helpDoes caveman make answers dumber?expand_more
      
    No. It changes how the agent talks, not what it knows. Technical terms, code blocks, commands and error messages stay exact. A March 2026 paper tested 31 models and found brevity limits improved accuracy by ~26 points on some benchmarks.
    
    
    helpWhat about security warnings or risky commands?expand_more
      
    Caveman switches back to normal, clear sentences for security warnings, irreversible actions, and step-by-step instructions where short fragments could be misread. Then it resumes.
    
    
    helpI don't write in English. Does it work?expand_more
      
    Yes. Write Portuguese, caveman grunts Portuguese. Spanish, French, Turkish — same. It compresses the style and never translates. wenyan mode is the one exception on purpose: classical Chinese packs the most meaning per token.
    
    
    helpInstall broke. Now what?expand_more
      
    Open your agent inside the caveman repo and say: "Read CLAUDE.md and INSTALL.md, install caveman for me." Agent read repo, agent fix own brain. Still stuck? Open an issue.
